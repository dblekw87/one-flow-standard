# ONE FLOW STANDARD Portfolio

경력 UI/UX 디자이너의 작업물을 소개하는 인터랙티브 포트폴리오입니다. 공공 서비스, 브랜드 웹사이트, 캠페인 마이크로사이트, 모바일 애플리케이션, 사내 시스템 등 다양한 디지털 프로젝트를 하나의 흐름으로 탐색할 수 있도록 구성했습니다.

## Portfolio Focus

- UI/UX 전략, 정보 구조 설계, 화면 설계, 디자인 시스템, 비주얼 디렉션 작업을 중심으로 정리
- 프로젝트별 대표 화면을 1920x1080 기준 이미지 섹션으로 제공
- 각 상세 페이지의 Figma Link 버튼을 통해 해당 Figma 작업 노드로 바로 이동
- 데스크톱, 태블릿, 모바일 해상도에서 이미지가 끊기거나 불필요한 여백이 생기지 않도록 반응형 비율 적용

## Featured Work

- 서울아리수본부 사이버 고객센터 홈페이지
- 한화 보훈 캠페인 마이크로 페이지
- 머크코리아 안전출입관리 시스템
- 대웅제약 브랜드 홈페이지
- 대웅바이오 브랜드 홈페이지
